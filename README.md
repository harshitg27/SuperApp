# SuperApp - Watch Movies and More 🎬📰

## 🚀 Project Overview
SuperApp is a **Frontend application built with React.js** that offers a **multitasking experience**, allowing users to:
- **Watch movies**
- **Check the weather**
- **Manage notes**
- **View the latest news**
- **Use a countdown timer**
- **Access their user profile**

## 🌟 Features
- **Form Validation**: Ensures user input is error-free.
- **State Management**: Utilizes **Redux** for efficient state handling.
- **Multi-Utility Dashboard**: A single platform for different tasks including weather updates, movies, notes, countdowns, and news.

## 🛠 Tech Stack
- **Frontend**: React.js
- **State Management**: Redux
- **Styling**: Modular CSS

## 📂 Project Structure
```
SuperApp/
│-- src/                # React Source Files
│-- components/         # Reusable Components
│-- redux/              # Redux Store & Actions
│-- assets/             # Static Images & Icons
│-- styles/             # Modular CSS Files
│-- App.js              # Main Application File
│-- index.js            # Entry Point
```

## 🔧 Installation & Setup
1. **Clone the repository**
   ```sh
   git clone https://github.com/harshitg27/SuperApp.git
   cd SuperApp
   ```
2. **Install dependencies**
   ```sh
   npm install
   ```
3. **Run the application**
   ```sh
   npm run dev
   ```
